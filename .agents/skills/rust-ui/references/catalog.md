# Capability catalog

Use the live documentation for exact APIs. This index is for selection.

- **Disclosure and overlays:** Accordion, Collapsible, Dialog, Alert Dialog,
  Sheet, Drawer, Popover, Hover Card, Tooltip, Context Menu, Dropdown Menu,
  Menubar, Navigation Menu, Command.
- **Forms:** Field, Form, AutoForm, Label, Input, Input Group, Input OTP, Input
  Phone, Input Prompt, Textarea, Checkbox, Switch, Radio Group, Radio Button,
  Radio Button Group, Toggle Group, Select, Multi Select, Combobox, Date Picker,
  Slider, Chips, Dropzone.
- **Data:** Table, Data Table, Data Grid, Pagination, Progress, Status, Stepper,
  Badge, Kbd.
- **Content and layout:** Card, Item, Alert, Callout, Empty, Separator,
  Breadcrumb, Tabs, Aspect Ratio, Scroll Area, Carousel, Card Carousel, Marquee,
  Bottom Nav.
- **Feedback and motion:** Toast, Sonner, Spinner, Skeleton, Shimmer, Animate,
  Animate Group, Drag and Drop, Pressable, Button Action.
- **Messaging:** Message, Bubble, Attachment, Marker.
- **Identity and appearance:** Avatar, Theme Toggle, Direction Provider.
- **Charts:** area, bar, line, pie, radar, and radial chart families, with
  interactive, legend, grid, gradient, stacked, and other documented variants.
- **Hooks:** copy clipboard, history, horizontal scroll, mobile detection, body
  scroll lock, locks, media query, press-hold, and random identifiers.
- **Icons:** the searchable Rust/UI Icons catalog exposes Lucide-derived Rust
  components and interactive size/color previews.
- **Tooling:** CLI installation/add flow, theme builder, RTL guidance, registry
  source, desktop catalog browser, Figma/changelog documentation.
